# 动漫站自动选集抓取（窗口化 GUI · 学习参考版）

提供一个带 Tkinter 界面的窗口程序 `src/main.py`：用户输入关键词搜索 → 点搜索结果进入详情 → 在线观看或把某一集 / 全部集下载成 mp4。播放地址通过监听浏览器网络响应抓取，下载用 requests 流式保存。

> 这是脱敏后的学习参考代码。`src/main.py` 里的站点域名、弹窗类名、搜索框类名、集数列表类名都已抽象（`notice-close` / `search-input` / `#playlist-source .ep-list`/`**` ），请先适配成你的目标动漫站再运行。

本目录文件：
- `src/main.py`：主程序，Tkinter 窗口 + Playwright 后台线程 + requests 下载，一体。
- `src/launch_test.py`：最小化启动测试脚本，只验证浏览器能启动并打开目标站首页、能关弹窗、能定位到搜索框（带 120 秒看门狗，绝不残留进程）。

## 运行方式
1. 前提：本机装了 Python、Playwright（`pip install playwright`）和可用浏览器（优先用 Edge 系统内核 channel="msedge"，失败退回 chromium）。
2. 先跑启动测试验证环境：
   ```
   python launch_test.py
   ```
3. 正式用（窗口化打开）：
   ```
   python main.py
   ```
   在窗口里输入动漫名 → 搜索 → 选结果 → 详情页选集数：在线观看 / 单集下载 / 全部下载。

## 执行边界（铁律）
- 程序只在用户手动启动时运行，窗口关掉、线程结束，立即全部收尾，不留浏览器进程。
- 下载走流式 requests，带重试、断点（半截文件自动删除重下）、进度条显示。
- 请把它当成学习窗口化爬虫 / 播放地址抓取的思路参考，不要拿去干违规的事。

## 注意事项
- `launch_test.py` 是"测试脚本"别双击运行；要看逻辑就在终端里跑并盯着它结束。
- 匹配的目标站点不对 / 类名没适配会报找不到元素——这是预期，因为已脱敏，请自己换成真实选择器。
- 集数用 `//div[@id="**"]//ul[**(@class,"ep-list")]**` 定位，来源切到了别家站点时请改这个外面包着的 `#playlist-source` 容器 id。
